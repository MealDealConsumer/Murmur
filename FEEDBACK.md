# Dictation feedback

Problems Claude chats noticed in dictated messages that the dictionary cannot fix: a spoken instruction left in the
text, a filler or stutter left in, a sentence mangled. Read this before changing the app, fix the cause, then delete
the line. **This file is in a public repo**, so quote only the words that went wrong, never anything private.

One line each, newest at the bottom:

    - 2026-11-08, VS Code: "the text exactly as it arrived". What was wrong with it.

Misheard names and terms do not go here. They go straight into the dictionary with `murmur add`.
- 2026-11-08, VS Code: "Hopefully we can make it so that murmur is contextual." Feature idea, not a mishearing: the owner would like Murmur to pick the right word from context the way a reader does, for example "lead ward" in a sentence about a game being "leaderboard" and "male dealer" being their username MealDealer, rather than needing each one added by hand.
